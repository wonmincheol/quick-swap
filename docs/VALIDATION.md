# Quick Swap 0.3.x 검증 기록

검증일: 2026-09-13

## 실행 환경과 결과

- 설치된 Factorio 2.1.17 실행 파일을 사용했다.
- 0.3.0/0.3.1 초기 구현: 바닐라 41개, Space Age 43개 통합 검사 및 재로드 검사 통과.
- 0.3.2/0.3.3 편집 개선: 바닐라 63개, Space Age 65개 통합 검사 및 재로드 검사 통과.
- 0.3.4/0.3.5 위치 편집 제거: 바닐라 55개, Space Age 57개 통합 검사, 키 재할당 및 재로드 검사 통과.
- 별도 키 재할당 검사에서 F6~F9로 설정한 네 방향 키가 게임의 번역 결과와 화면에 표시되는 것을 확인했다.
- 실제 게임 GUI 캡처에서 그룹 제목줄, 10칸 배열, 자동 추가된 빈 행,
  전체 사용 설정, 순환 설정, 하단 안내와 적용·취소 버튼을 확인했다.
- 테스트는 임시 모드·세이브·설정 디렉터리에서 실행했다. 사용자 모드 및 세이브는 수정하지 않았다.

## 자동으로 확인한 동작

- 기본 그룹 생성, 일반 건설 아이템 지원, 청사진 제외, 초기 연구 해금 판정.
- 가로·세로 이동, 가로 순환, 세로 끝 정지, 빈칸·빈 행 건너뛰기.
- 그룹 우선순위, 다른 그룹으로 넘어가지 않는 동작, 전체 사용 중지.
- 실제 GUI 생성, 10열 고정, 마지막 행 사용 시 빈 행 생성, 끝의 빈 행 정리.
- 같은 그룹 내 중복 거부, 미해금 아이템 등록 거부.
- 사라진 아이템의 좌표 유지와 우클릭으로 해당 슬롯 비우기.
- 그룹 추가·이름 변경·삭제, 임시 편집, 적용·취소, 닫을 때 변경 폐기 확인.
- 플레이어별 설정 분리(서로 다른 플레이어 인덱스의 저장 데이터).
- 정상 인벤토리 교체와 수량 보존, 인벤토리 포화 시 부분 삽입의 정확한 롤백.
- 입력 핸들러 연결, 성공 시 줌 잠금 및 다음 틱 복원, 편집 창을 연 동안 전환 중지.
- 원격 커서 교체, 연구 변경 후 해금 캐시 갱신.
- Space Age에서 최고 보유 품질 선택과 원격 커서의 전설 품질 유지.
- 실제 저장 파일 재로드 후 설정과 열린 편집 창 유지.
- 그룹 위·아래 이동과 경계 버튼, 화면 순서·데이터 순서·탐색 우선순위의 일치.
- 위치 편집 UI가 없고 기본 선택기가 잠기지 않으며 일반 클릭이 이동 출발 칸을 선택하지 않는지 확인.
- 우클릭 비우기와 취소 시 슬롯 복원 확인.
- 그룹 순서를 변경한 실제 저장 파일을 재로드해 순서와 기존 슬롯 위치 유지 확인.

## 사용자 수동 테스트 결과

0.3.0/0.3.1 초기 구현을 원격 데스크톱 환경에서 사용자가 확인한 결과다. 아래 내용은 자동 검사 결과와 구분한다.
사용한 외부 모드명과 게임 버전은 별도로 기록되지 않았다.

- 다른 키보드 키로 입력을 재할당했을 때 정상 동작했다.
- 원격 환경에 마우스를 추가해 Shift/Ctrl+휠 입력도 정상 동작하는 것을 확인했다.
  로컬 데스크톱에서의 직접 입력은 후속 확인이 필요하다.
- 바닐라·DLC 아이템뿐 아니라 외부 모드가 추가한 새로운 아이템에서도 전환이 동작했다.
- 일반 캐릭터와 지도·원격 보기의 아이템 사용 규칙이 모드 아이템에서도 정상 동작했다.
- 배열 경계, 빈칸·사용 불가 항목 건너뛰기, 축별 순환 및 그룹 중복 처리에 문제가 없었다.
- 테스트한 모드 아이템의 해금 처리에 문제가 없었다.
  레시피 없이 지급되는 모든 특수 아이템까지 지원한다고 일반화하지 않는다.
- 팝업에서 적용한 뒤 게임을 저장하고 여러 번 종료·재실행했을 때 설정이 유지됐다.
- 실제 멀티플레이 테스트는 추후 진행하기로 했다.

설정 적용은 현재 게임 상태에 반영하는 단계이며, 재실행 후 보존하려면 해당 게임을 저장해야 한다.

## 재현

```powershell
python tools/test_runtime.py 'C:\Program Files (x86)\Steam\steamapps\common\Factorio\bin\x64\factorio.exe'
python tools/test_runtime.py 'C:\Program Files (x86)\Steam\steamapps\common\Factorio\bin\x64\factorio.exe' --space-age
python tools/test_runtime.py 'C:\Program Files (x86)\Steam\steamapps\common\Factorio\bin\x64\factorio.exe' --rebound
python tools/test_runtime.py 'C:\Program Files (x86)\Steam\steamapps\common\Factorio\bin\x64\factorio.exe' --space-age --rebound
```

스크립트는 임시 복사본에만 테스트 진입점을 추가하고, 테스트용 게임 프로세스만 종료한다.
GUI 검증을 위해 숨김 창으로 그래픽 클라이언트를 실행하고, 재로드는 헤드리스 벤치마크로 확인한다.
스크린샷은 `dist/tests`에 저장한다. 테스트 코드는 배포 ZIP에서 제외한다.

## 남은 수동 검증 범위

- Factorio 2.0 실행 파일에서의 실게임 검증: 현재 설치 환경에는 2.1.17만 있다.
- 두 실제 멀티플레이 클라이언트의 동기화와 재접속.
- 로컬 데스크톱에서 직접 Shift/Ctrl+휠 조작 확인. 원격 환경에 연결한 마우스에서는 확인됐다.
- Esc로 변경 폐기 확인, 청사진 책자의 바닐라 입력과 다른 모드의 단축키 충돌에 대한 개별 확인.
  자동 검사는 GUI 이벤트와 입력 핸들러를 게임 API로 호출한다.
- 실제 외부 모드 제거 후 사라진 아이템 슬롯 처리. 자동 검사에서는 없는 아이템 이름으로 확인했다.
- 대규모 모드 구성과 매우 긴 배열의 사용성·성능. 현재 모든 행의 슬롯 GUI를 생성한다.
- 새 그룹 순서 버튼의 실제 마우스 조작. 자동 검사는 동일 핸들러를 게임 API로 호출한다.

그룹 복제·프리셋 복원은 이번 구현에서 제외했다. 순서 변경은 0.3.2/0.3.3에서 추가했다.
클릭 방식 위치 편집은 사용자 요청에 따라 0.3.4/0.3.5에서 제거했다.
공식 자료와 API 선택 근거는 [편집 API 참고 기록](EDITOR_API_REFERENCES.md)에 정리했다.
